## 10.11.2026 — поставка преподавателю

**[У] По заданию владельца:** раздельные обычная Web-версия для Docker/Git и Windows x64 ZIP с существующим F1; никаких изменений механик, публикации Git и отправки письма. Владелец дополнительно подтвердил оба способа доступа к удалённому серверу: с доменом и без него.

**Технические решения поставки:** свежий release хранится в `deploy/web/` с gzip и SHA256, поэтому на сервере не нужен Godot; Docker использует Nginx, а необязательная HTTPS-конфигурация — Caddy. Без домена предусмотрен SSH-туннель на localhost: шаблон Godot требует secure context и не запускается по обычному HTTP удалённого IP. Windows Teacher использует feature tag и отдельный каталог сохранений; sandbox и его запрет записи переиспользованы. В старой панели две команды обобщены на фактическое здоровье босса вместо константы 9. [.gitignore/.gitattributes и результаты](TEACHER_HANDOFF.md) фиксируют границы публичной поставки. Эти изменения не вводят новых правил игры.
