MARICRAFT — Windows x64, версия для проверки преподавателем
Godot 4.7.2 Standard. Установка Godot, Docker и сервера не требуется.

1. Извлеките ZIP целиком в отдельную папку. Не запускайте игру внутри архива.
2. Дважды щёлкните MARICRAFT.exe. MARICRAFT.pck должен лежать рядом.
3. Для обычной игры: «Новая игра» → герой → «Подтвердить выбор» → «Продолжить».

РЕЖИМ БОГА
Нажмите F1 (на некоторых ноутбуках Fn+F1).
Выберите «Начать тестовую сессию», затем «Заново · 1-1» или любой из девяти уровней.
Снова F1 → включите «Бесконечные сердца» и «Неуязвимость». Закройте панель кнопкой
«Закрыть» или F1. При смене уровня флаги сбрасываются: включите их заново.
«Полёт (стрелки)»: вверх/вниз — высота, A/D — движение по горизонтали. Падение в пропасть
возвращает героя на маршрут; бесконечные сердца не дают закончиться жизням.

F1 также позволяет выбрать форму, добавить 100 монет, изменить скорость,
перейти к привалу/финишу. На 1-3, 2-3 и 3-3 доступны «Босс · …» (перенос к арене),
«Восстановить босса», «Победить босса». Есть стенд анимаций и показ коллизий.
Чтобы вернуться к своему прохождению: F1 → «В обычный профиль».

УПРАВЛЕНИЕ
A/D — движение; пробел — прыжок;
E — выстрел в магической форме; S/стрелка вниз — вход в трубу; Esc — пауза.
Выход: кнопка закрытия окна или Alt+F4.

СОХРАНЕНИЯ
Эта сборка использует отдельный каталог %APPDATA%\MARICRAFT-Teacher.
Изменения тестовой сессии не записываются в обычное прохождение этой сборки.
Сохранения браузера и обычного проекта Godot остаются отдельными и не удаляются.

Передавайте всю папку с EXE и PCK. Подключение к интернету для игры не нужно.
