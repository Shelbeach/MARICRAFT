# MARICRAFT: открыть в Godot и запустить

## Актуальный запуск после исправления камеры

1. Используйте **Godot 4.7.2 Standard**. В менеджере проектов нажмите **«Импортировать»**, укажите **`D:/Projects/MARICRAFT/project.godot`**, затем **«Импортировать и редактировать»**. Если проект уже в списке, выделите запись с этим путём и нажмите **«Редактировать»**.
2. Дождитесь окончания первого импорта. Выбирать главную сцену не требуется: уже назначена **`D:/Projects/MARICRAFT/scenes/boot/campaign.tscn`**.
3. Нажмите **F5**. В меню выберите новую игру или продолжение. Для движения — **A/D**, прыжка — **Пробел**, выстрела в магической форме — **E**. Если игровое окно не принимает ввод, один раз щёлкните внутри него.
4. Для остановки вернитесь в редактор и нажмите **F8** или квадратную кнопку остановки сверху справа. **Esc** в игре открывает паузу.

Браузер, сервер и ручная подготовка перед F5 не нужны. Рендерер остаётся Compatibility. Открывать `exports/`, `qa/` или тестовые проекты в `reports/temp/` для игры не нужно.

### Открыть и изменить конкретный уровень

В панели **«Файловая система»** раскройте `res://scenes/levels/`. Дважды щёлкните файл и выберите вкладку **2D** сверху:

| Уровни | Полные пути |
|---|---|
| 1-1, 1-2, 1-3 | `D:/Projects/MARICRAFT/scenes/levels/forest_1_1.tscn`, `forest_1_2.tscn`, `forest_1_3.tscn` в той же папке |
| 2-1, 2-2, 2-3 | `D:/Projects/MARICRAFT/scenes/levels/durotar_2_1.tscn`, `durotar_2_2.tscn`, `durotar_2_3.tscn` в той же папке |
| 3-1, 3-2, 3-3 | `D:/Projects/MARICRAFT/scenes/levels/molten_3_1.tscn`, `molten_3_2.tscn`, `molten_3_3.tscn` в той же папке |

В дереве **«Сцена»** слева выберите нужную платформу, монету или сундук. Декоративные объекты лежат в узле **Scenery**. Справа в **«Инспекторе» → Transform → Position** можно менять X/Y; **Ctrl+S** сохраняет эту же игровую сцену. Проверяйте результат через F5. Коллизия платформы связана с её узлом; визуальные подпорки рассчитываются из реального расположения поверхностей.

Плагин **MARICRAFT Levels** в `addons/maricraft_levels/` включён и даёт статический предпросмотр. Служебные элементы предпросмотра не нужно сохранять как собственные узлы. Полные анимации, эффекты и боссов смотрите в игре. Выбор/перетаскивание мышью в GUI в этом этапе не перепроверялся; выбор через дерево и значения Position позволяет работать без такого предположения.

Для проверки отдельного уровня с игровым интерфейсом: **F5 → F1 → «Начать тестовую сессию» → «Заново · 1-2»** (или другой номер). Это тестовый профиль. **F6** запускает открытую сцену отдельно и не заменяет запуск кампании с её состоянием.

Сохранения браузерной и настольной версий раздельные; существующие сохранения не удалялись.

[Подробный отчёт и границы проверки](CAMERA_REPAIR_REPORT.md) · [Видео и сравнения](../reports/CAMERA_REPAIR_REVIEW.html). Сам редактор через GUI в этой задаче не управлялся по прямому указанию владельца; следующие разделы сохраняют историю предыдущих проверок.

## Где смотреть уровни

В панели **«Файловая система»** слева раскройте `res://scenes/levels/` и дважды щёлкните нужный файл:

- `forest_1_1.tscn` — лесная тропа 1-1;
- `forest_1_2.tscn` — переправа и грот 1-2;
- `forest_1_3.tscn` — дозор вожака 1-3.
- `durotar_2_1.tscn`, `durotar_2_2.tscn`, `durotar_2_3.tscn` — вторая глава;
- `molten_3_1.tscn`, `molten_3_2.tscn`, `molten_3_3.tscn` — Огненные Недра.

В версии 0.7.0 для быстрой проверки новой главы: **F5 → F1 → «Начать тестовую сессию» → «Заново · 3-1»**. Аналогично доступны 3-2 и 3-3. Тестовая сессия не записывает читы в обычный профиль. Для обычной игры продолжайте кампанию; свободная карта всех девяти уровней открывается после Рагнароса.

Для просмотра сцены выберите вкладку **2D** сверху. Часть графики создаётся при запуске, поэтому полный вид смотрите в игре. Для перехода без прохождения: F5 → новая/продолженная кампания → **F1** → «Начать тестовую сессию» → «Заново · 1-2» или «Заново · 1-3». Это отдельный диагностический профиль. «Стенд анимаций» в F1 позволяет выбрать героя, форму и любой клип, остановить и перелистывать кадры.

Основное меню: `D:/Projects/MARICRAFT/scenes/boot/campaign.tscn`; герой: `scenes/actors/forest_player.tscn`; обычный лесной враг: `scenes/enemies/murloc.tscn`; код отображения: `scripts/visual/`.

Если предпочитаете отдельное окно, в меню с тремя точками у игрового вида Godot снимите **«Встроить игру»**, затем F8 → F5. Это настройка редактора, рендерер игры менять не нужно.
